# Monitoring Operasional BBM

**Fuel Operations Analytics — Regional Jatimbalinus**

## Overview

Monitoring Operasional BBM merupakan prototipe dashboard interaktif yang dikembangkan sebagai bagian dari portofolio akademik dan persiapan Kerja Praktik.

Proyek ini menerapkan konsep **Data Analytics, Business Intelligence, dan Data Visualization** untuk menyajikan informasi penerimaan, penyaluran, persediaan, serta biaya logistik BBM secara terstruktur dan mudah dipahami.

Live Dashboard

Akses prototipe dashboard melalui tautan berikut:

https://feyshakamilaa.github.io/PrototipeDashboard-BBM/

## Dashboard Features

- **Overview** — Ringkasan indikator utama operasional BBM.
- **Stok & Penerimaan** — Analisis penerimaan, persediaan, dan ketahanan stok.
- **Analisis Penyaluran** — Visualisasi distribusi BBM berdasarkan produk, wilayah, dan periode.
- **Susut & Biaya** — Monitoring tingkat susut dan efisiensi biaya logistik.

## Technology

Python, Pandas, HTML, CSS, JavaScript, dan Chart.js.

## Data & Project Scope

Dashboard menggunakan dataset sintetis dengan periode bulanan **2021–2025** untuk menggambarkan analisis operasional distribusi BBM di wilayah Jawa Timur, Bali, Nusa Tenggara Barat, dan Nusa Tenggara Timur.

## Disclaimer

**Prototipe ini dikembangkan secara independen untuk keperluan akademik dan portofolio.**

Seluruh data merupakan simulasi dan tidak merepresentasikan data aktual, kinerja operasional, maupun sistem internal PT Pertamina Patra Niaga.

Proyek ini bukan aplikasi resmi dan tidak berafiliasi dengan PT Pertamina Patra Niaga.
